# Problema y alcance

## Contexto

**Cerro Seguro** es un proyecto de seguridad y comunicaciones en montaña, con un prototipo de repetidor y telemetría ambiental.

El nodo descrito utiliza una base RAK19007, un módulo RAK4631 con nRF52840 y un sensor ambiental RAK1906 basado en Bosch BME680. El detalle del problema y las decisiones del Avance 1 deben incorporarse antes de definir criterios de éxito.
