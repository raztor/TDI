# Avances y antecedentes

Incorporar el Avance 1 y, cuando aporte contexto, el Avance 2. Están pendientes.

El Avance 1 debe permitir verificar el problema, usuario, necesidad y objetivos originales. Enlazar sus secciones relevantes desde [problema y alcance](../problema-y-alcance.md) y [validación](../../testing/validacion.md).

No publicar datos personales o material de terceros que no sea necesario para la evaluación.
