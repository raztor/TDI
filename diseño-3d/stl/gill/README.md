# STL originales por pieza: protector Gill

Ocho archivos originales del proyecto **Gill Shield Weather Station case for RuuviTag**, de **nerdaxic**, redistribuidos sin cambios geométricos para referencia y uso no comercial bajo **CC BY-NC 4.0**.

- Atribución y aviso sobre la marca Ruuvi: [ATTRIBUTION.txt](ATTRIBUTION.txt).

## Archivos

- `ruuvi_screen_ring.stl`: anillo.
- `ruuvi_screen_tag_holder.stl`: soporte para RuuviTag.
- `ruuvi_screen_roof.stl`: techo liso.
- `ruuvi_screen_roof_logo.stl`: techo con logotipo, alternativa al techo liso.
- `ruuvi_screen_floor.stl`: base inferior.
- `ruuvi_screen_stand_arm.stl`: brazo de soporte.
- `ruuvi_screen_stand_backplate.stl`: placa trasera de soporte.
- `ruuvi_logo.stl`: logotipo.

Estos archivos son piezas mecánicas del protector, no modelos de sensores o placas electrónicas. El sensor RuuviTag no está incluido. Los dos techos son alternativas. Se conserva un único archivo original del anillo, sin decidir todavía la cantidad necesaria en el montaje.

El formato STL no codifica unidades. Importar como milímetros y comprobar las dimensiones antes de fabricar. No se acredita compatibilidad mecánica con el montaje Cerro Seguro ni se ha realizado una prueba de impresión o ajuste.

## Placas y sensores pendientes

No se publican todavía STL de RAK19007, RAK4631, RAK1906, Heltec V3 ni LilyGO T3. Los modelos localizados son STEP del fabricante y no se ha verificado una licencia que permita redistribuirlos públicamente, tampoco sus conversiones a STL. Que un archivo sea descargable no implica permiso de redistribución.
