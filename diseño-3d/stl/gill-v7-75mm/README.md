# STL del Gill final V7

[Medidas, cantidades, orientacion y montaje](../../fusion/gill-v7-75mm/README.md). Paquete: [Gill_V7_STL_Margen75.zip](Gill_V7_STL_Margen75.zip).

La base y las piezas V3/V4/V5 incluidas se reutilizan sin cambios. Las piezas V7 definen el montaje actual: ocho aletas estandar, una terminal, tres guias de 235,5 mm, tapa inclinada y disco de antena. Las probetas son opcionales. Los componentes comerciales no se imprimen.
