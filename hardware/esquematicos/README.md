# Esquemático

Incorporar el archivo editable de la herramienta utilizada y su exportación `esquematico.pdf`. No hay archivos de circuito disponibles todavía.

El esquema debe incluir alimentación, componentes, conectores, etiquetas, pines y señales. Debe coincidir con [la BOM](../BOM.xlsx) y [las conexiones](../conexiones.md).

Registrar herramienta, versión, revisión de placa y fecha del montaje. Abrir el archivo fuente y el PDF en una copia limpia antes de cerrar la entrega.
