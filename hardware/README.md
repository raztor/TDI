# Hardware

El montaje actual utiliza RAK19007 + RAK4631 + RAK1906, pulsador SOS y estación Heltec V3.2 conectada al computador por USB. El conjunto solar usa panel 12 V / 25 W, controlador GC Li-ion 3S, BMS externo, batería 3S y convertidor USB de 5 V. El montaje LILYGO se conserva como antecedente de A2.
