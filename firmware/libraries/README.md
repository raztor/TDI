# Dependencias locales

Incorporar aquí únicamente bibliotecas que deban distribuirse con el firmware. No hay dependencias incorporadas todavía.

Para cada biblioteca, conservar su licencia y registrar nombre, versión, fuente y uso en [FUENTES.md](../../FUENTES.md). Cuando la plataforma tenga un gestor de paquetes, fijar las versiones en su manifiesto en lugar de copiar las bibliotecas instaladas.
